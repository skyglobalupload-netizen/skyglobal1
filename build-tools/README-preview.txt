============================================================

WHAT'S HERE
  index.html ........................ Sky Global Holding — home (single page)
  companies/fluiday-auto.html ....... Fluiday Auto — full company page
  assets/theme.css .................. shared design system (tokens, components, RTL)
  assets/app.js ..................... shared behaviour (bilingual toggle, reveals, counters, motion)

HOW TO VIEW
  Just open  index.html  in any modern browser (Chrome, Edge, Safari, Firefox).
  Everything is self-contained; fonts and the GSAP animation library load from
  their public CDNs, so keep an internet connection for the first load.

  Toggle language with the  العربية / English  button, top-right. The whole site
  mirrors to right-to-left in Arabic.

NOTES
  - The "SG" logo mark is a PLACEHOLDER geometric interpretation — it is wired to
    be swapped for your real logo file (SVG/PNG) with a one-line change.
  - Fluiday Auto product bottles are stylised 3D-look CSS/SVG renders (no external
    3D engine). If real product renders or .glb models are produced later, the
    product section is isolated so a true 3D viewer can drop in.
  - Every missing asset (partner logos, project photos, motorsport media, the
    interactive markets map) is shown as a clearly-labelled placeholder.
  - Numbers marked as placeholders in your source docs (founding year, partner
    count, sector count) are labelled as such on the page.
  - English copy is a professional draft translation of your Arabic source docs;
    native Arabic proofing is still recommended before launch.
